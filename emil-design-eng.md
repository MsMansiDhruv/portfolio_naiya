**Description:** This skill encodes Emil Kowalski's philosophy on UI polish, component design, animation decisions, and the invisible details that make software feel great.

**Usage:** Governs animation decisions, component building, and UI review processes. Ensures design engineering quality across the portfolio.

**Key Principles:**
- **Taste is trained, not innate** - Focus on what elevates interfaces beyond functional
- **Unseen details compound** - Every small decision creates cumulative polish
- **Beauty is leverage** - Excellent defaults and animations differentiate quality
- **Review Format** - Must use markdown tables with Before/After/Why columns for UI reviews
- **Animation Framework** - Comprehensive decision tree for when/why/how to animate
- **Component Building** - Buttons must feel responsive, avoid scale(0), popover positioning
- **Performance Rules** - Only animate transform/opacity, use CSS transitions over keyframes
